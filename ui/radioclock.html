How pairing & manual sync work

Bluetooth and LF radio transmission are mutually exclusive. RadioClock turns Bluetooth off whenever a radio transmission is active.

Pair a GW‑BX5600
1. In Settings → Watch pairing, select the watch profile and GW‑BX5600 MIP protocol.
2. Press Pair Watch.
3. On the watch, hold C for at least 3 seconds until the Bluetooth symbol and CONNECT WITH A PHONE flash.
4. RadioClock learns the watch only after the connection and time write succeed.
Trigger a manual sync
1. Select the paired watch profile and press Sync selected watch now.
2. On a GW‑BX5600 in Timekeeping Mode, press D once to request immediate time correction.
3. If a previous wait window is already open, pressing Sync again restarts it instead of returning a generic busy error.
Always wait mode
When enabled, RadioClock continuously listens for sync requests from the selected paired watch. It never learns an unknown watch in this mode. Listening automatically stops for every scheduled RF transmission and resumes afterwards.
