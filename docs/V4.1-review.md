# RadioClock V4.1 sidebar correction — 6 October 2026

V4.1 restores the approved mockup's fixed left sidebar at every screen width. All eight labelled items remain visible: Overview, Radio, Watch (BLE), Schedules, Network, Settings, Diagnostics and About. Each opens a distinct page.

The previous narrow-screen bottom navigation hid Schedules, Network and About. That behavior has been removed. Sidebar width is 278px on desktop, 208px on intermediate screens and 164px on phones; the main content sits alongside it. The desktop sidebar/content positions were checked against `ui/v32_ui_mockup.png`.

Radio and LF schedule pages move the same existing controls from their overview positions and return them when navigation changes. No duplicate control IDs are introduced, and unsaved schedule values survive. Network now contains Wi-Fi network/power controls; Settings retains time-zone and watch-pairing controls. About is separate from Diagnostics.
