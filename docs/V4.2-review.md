# RadioClock V4.2 review

## Scope

V4.2 fixes automatic Casio Bluetooth scheduling while preserving the V4.1 dashboard, Bluetooth packet protocols, LF encoders and RF timing.

## Bluetooth scheduler changes

- Automatic targets remain 00:30, 06:30, 12:30 and 18:30 by default.
- Automatic targets are interpreted in the independent Bluetooth timezone and Bluetooth-only offset.
- Each target has a listening window from 5 minutes before through 5 minutes after.
- The ESP32 may enter an automatic window late anywhere inside that window.
- JJY/LF retains absolute priority; BLE is fully shut down while RF is active.
- If RF clears before the Bluetooth window closes, the automatic slot can resume.
- A partial RF overlap no longer disables the entire Bluetooth slot.
- If RF occupies the whole ±5-minute Bluetooth window, that watch attempt cannot be received.
- Always Wait pauses during RF and resumes after RF ends.

## UI

The Automatic watch sync schedule controls are on the Schedules page. Watch (BLE) keeps pairing, manual sync, timezone/offset and Always Wait controls.

## Clock error diagnostic

The displayed estimated clock error includes a fixed 0.20 second baseline uncertainty. V4.2 does not change that clock-confidence model.

## Validation

Repository build/test paths now point at the V4.2 sketch. The Bluetooth workflow host test includes a regression for late entry into an automatic window after the nominal target minute. Physical watch reception and RF output remain hardware acceptance tests.
